#Locators
A locator which explains the element on the web page which we want to interact with.
page.locator(".form-control")
page.locator("#name")

page.get_by_placeholder("Enter Name")

Browser: chrome,edge, firefox
Browser context-- isolated browser
Page--current browser page

page.locator
id : #name
class: ".form-control"
